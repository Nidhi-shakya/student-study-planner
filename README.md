# Student Task and Study Planner - MCA Project

## 1. Project Overview
Student Task and Study Planner is a student-centric study timeline and topic management application developed for MCA Continuous Assessment. It allows students to select or add subjects, specify what they want to learn in each subject, assign target study dates, and automatically determine what they have to study first based on date urgency and priority alert levels.

## 2. Core Features

### A. Add Subject and What To Learn
- Select an existing subject or add any new custom subject.
- Detail exactly what concept, topic, or lesson you want to learn.
- Specify target study date and estimated study hours.
- Set priority alert level (High Study First, Medium, Low).

### B. Study First Timeline (What To Study First)
- Chronological and priority sequence automatically arranges topics into a ranked study order.
- Prominent Rank Badges (Rank 1: Study First, Rank 2: Study Next, Rank 3: Scheduled).
- Priority Alert Banner dynamically surfaces the most urgent topic at the top of the dashboard.
- Clear countdown days remaining or overdue indicators.

### C. Full CRUD Operations
- Create: Add topics to study timeline.
- Read: Display chronological study queue with subject and status filters.
- Update: Edit topic title, subject, target date, or toggle completion checkbox.
- Delete: Remove topic with confirmation.
